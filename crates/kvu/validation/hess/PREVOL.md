## 2. Bornes d'arrondi (règle « identité en F64 à seuil < 1e-12 » : HESS-REG, seuil 1e-12)
Estimation (non démonstration) : chaque composante de H·v somme au plus 6 plaquettes ; par plaquette ≤ 3 produits de rotation 3×3 (15 flops chacun), 2 produits vectoriels et ≤ 24 additions, soit n ≲ 100 opérations flottantes sur le chemin d'une composante ;
erreur ≤ γ_n Σ|termes|, γ_n ≈ n u = 1,1e-14, avec Σ|termes| ≲ 4 · Schur(H) · ‖v‖∞ (facteur 4 de marge pour les termes intermédiaires) : borne ≈ 5e-14 · (Schur ‖v‖∞) ≪ 1e-12. Le port de `ym4_hess` suit le même ordre d'opérations : l'écart mesuré en essai est exactement 0.

## 3. Définitions, agrégations et avenants (gelés ici)
- **HESS-REG** (avenant **A1**). Norme : ‖Δ‖∞ / (Schur(H_op) ‖v‖∞) où H_op est l'opérateur COMPARÉ : Schur(H_ym4) (`op.schur()` d'ym4_hess) en base ym4 ; Schur(H_s2) = Schur(H_ym4)/2 en base s2 (H_s2 = H_ym4/2 à une permutation près). Le texte gelé écrit « Schur(H) » sans préciser ;
  la convention précédente (dénominateur Schur(H_ym4) en base s2) doublait la tolérance relative en s2 : elle est abandonnée, A1 est plus stricte pour le PASS. Statistique PASS : maximum sur les 5 fonds et 22 vecteurs ; PASS ssi ≤ 1e-12 en base ym4 ET en base s2.
  Mutant « facteur 2 omis » (`--mutant facteur2`, base s2) : ROUGE exigé = (minimum sur les fonds du maximum sur les vecteurs de la même norme) ≥ 0,1 [lecture stricte, par fond] ET diagnostic indépendant du dénominateur min sur les vecteurs de ‖H_mut v − H_ref v‖₂/‖H_ref v‖₂ ≥ 0,9
  (un doublement pur vaut 1). Déclaré : avec l'ancien dénominateur Schur(H_ym4), la lecture stricte donnait 0,075 à 0,123 par fond (échec de la lecture stricte sur 3 fonds) : le dénominateur A1 est choisi pour la raison ci-dessus (opérateur comparé), non pour sauver le mutant, mais il a été adopté après avoir vu ces nombres.
- **HESS-EXACT** : 4⁴, base s2, H assemblée par H·v sur la base canonique (3072 colonnes) ; β = 2,3 (Haar) et β = 8 (gaussien) ; référence lat.py × β ; max|ΔH|/max|H| ≤ 1e-10 pour (a) gauche et (b) additif, 2 fonds ; symétrie de H assemblée rapportée.
- **G1** (avenant **A2**). 4⁴, 2 fonds (graines 031, 032), 10 paires (ζ, ξ) par fond à support sur ≤ 6 liens (les 4 liens d'une plaquette tirée + 2 liens tirés) ; **ζ et ξ normalisés à 1 ; ζ+ξ utilisé sans renormalisation**. q(d) := d²/ds² S(chart(s d)) en 0 par différences secondes centrées,
  Richardson (h, h/2, h/4 ; h = 1e-3) : R1 = (4D(h/2) − D(h))/3, R2 = (4D(h/4) − D(h/2))/3, q = (16 R2 − R1)/15 ; ⟨ξ,Hζ⟩_FD = (q(ζ+ξ) − q(ζ) − q(ξ))/2 ; seules les plaquettes touchant les liens du support entrent dans S. **Arithmétique : l'action est évaluée en précision étendue
  (numpy.longdouble, 80 bits) ; D(h) est converti en float64 avant Richardson** ; chart gauche : q_l ← exp(i a_l·σ/2) q_l ; chart additif : q_l ← exp(i (A_l + a_l)·σ/2) (A = log principal ; le point central est chart(0)). Deux échelles pour l'erreur relative :
  (H) max(|⟨ξ,Hζ⟩|, |⟨ζ,Hζ⟩|, |⟨ξ,Hξ⟩|) [du H testé] et (FD) max(|FD(ξ,ζ)|, |q(ζ)|, |q(ξ)|) [indépendante de H, ajoutée par A2]. PASS ssi le maximum sur fonds, paires, deux charts et deux échelles ≤ 1e-6.
  **M-b** (`--mutant M-b`, mêmes paires) : pour chaque fond, chart et échelle, maximum sur les paires de l'erreur relative ; ROUGE exigé : minimum sur les fonds, charts et échelles de ces maxima ≥ 0,1.
- **G2** : H(U = 1), base s2, β = 1, assemblée par colonnes (lots de 1024 vecteurs de base) à 4⁴ et 6⁴ ; max|ΔH| / max|Q0| ≤ 1e-10 (Q0 = ¼ RᵀR ⊗ I₃ de lat.Geo).
- **G3** : Ω_x = première direction du tirage Haar de graine 26102613021 (L = 4), U = lat.gauge_transform(froid, Ω), β = 2,3. T-cov : `lmin --espace tcov --coord gauche --reference qcov`, |ε′| ≤ 1e-9. T-fix : fond fixé par `lat.landau_fix(tol 1e-26, maxit 20000)`,
  `lmin --espace kerB --coord additive --reference q0` (T-fix-fluct de S2, l'espace de G3a de S2), |ε′| ≤ 1e-6. **M-c** : même `lmin` sur le fond NON fixé : |ε′| ≥ 1e-3. Déclaré : G3-tcov (jauge pure) et KERDU(i) (U = 1) vérifient essentiellement H = Q ; ils ne valident pas les projecteurs à eux seuls
  (les projecteurs sont validés par HESS-LMIN contre scipy dense, HESS-ESPACES contre lat.py, HESS-KERDU (ii) (iii)).
- **HESS-LMIN** (avenant **A5**). 4⁴, 3 fonds (graines 041, 042, 043 ; β = 2,3 ; 8 ; 64), espaces libre, kerB (additif, q0) et tcov (gauche, qcov) ; LOBPCG `--tol 1e-10 --graine 1 --bloc 4`, projecteur `auto` (SVD à ≤ 1500 lignes de contraintes : SVD ici) ;
  référence dense scipy.linalg.eigh(PᵀHP, PᵀQP), P = `lat.basis_fix`/`lat.basis_cov` ; |Δλ_min| ≤ 1e-8 max(1, |λ_min|) ; résidu projeté calculé en Python avec les matrices denses de lat.py sur le vecteur rendu par kvu (normalisé vᵀQv = 1), ‖Pᵀ(Hv − λQv)‖/(‖PᵀHP‖₂ ‖Pᵀv‖) ≤ 1e-9 ;
  dimension de X de kvu = nombre de colonnes de P ; **A5 : critères ajoutés** : ‖v − PPᵀv‖/‖v‖ ≤ 1e-9 (vecteur dans X) et |vᵀQv − 1| ≤ 1e-9 AVANT la renormalisation Python (le vecteur rendu est Q-normalisé). PASS ssi les 9 cellules passent.
- **HESS-ESPACES** : pipeline de `S2/prod.py` : A = Gauss.draw(coarse = grossier/plein), U = su2_exp(A), `landau_fix(tol 1e-24, maxit 5000)`, A_f = su2_log(U_f) ; ε′_lat par `gen_eig_extremes` dense (Vfl = kerB, Vpl = libre/landau, Vc = tcov) ; ε′_kvu par `lmin`
  (kerB additif q0, landau additif q0, tcov gauche qcov) ; |Δ| ≤ 1e-8 sur les 9 cellules (3 fonds × 3 traitements). - **HESS-JVP** : L = 6, 3 fonds (Haar 061 ; `su2 gen` β = 2,8 graine 062 ; β = 8 graine 063), 20 directions gaussiennes non normalisées par fond (graines 064, 065, 066) ; **aucune réduction des fonds ou des directions n'est possible** (variables d'environnement supprimées). f(h) = 2 vec(log(Ū(h) Ū(0)†)),
  Ū = `kvu rg bloc` (c16), perturbation U_l → exp(i (hζ_l/2)·σ) U_l ; C(h) = (f(h) − f(−h))/(2h) ; Richardson (h, h/2, h/4) comme G1 ; **h = 2,5e-4** (calibrage : §5, choisi après observation) ; erreur = ‖FD − DŪ·v‖₂/‖DŪ·v‖₂ ≤ 1e-8 sur les 3 fonds × 20 directions.

  ‖DŪ x‖/‖x‖ ≤ 1e-10 avec le DŪ dual de kvu ET avec le Jacobien analytique indépendant (`kerdu_ref.py`, balaban_np.py), et ‖G_jauge x‖/‖x‖ ≤ 1e-10 avec les générateurs indépendants de la jauge résiduelle (le projecteur ne contrôlait pas seul l'orthogonalité à la jauge) ;
  (iii) dim de kvu = dim du script indépendant `ref_dim_kerdu.py` (SVD dense numpy de [J ; générateurs], rang à 1e-10 σ_max ; son JSON est haché AVANT le run de `hess_kerdu.py`), pour froid et Haar. Dérogation déclarée : (ii) est un échantillon ; la jauge résiduelle est traitée dans kvu par CG
  (rang vérifié par Cholesky du Gram), le Jacobien par SVD de Jacobi, contrairement à l'annonce générale « base orthonormée par SVD ».
- **Supplément NON gelé** : `hess_landau.py` (ID `INFO-LANDAU-*`) : `kvu hess landau` contre `lat.landau_fix` (4⁴, Haar 091 et gaussien β = 8 092, tol 1e-24), max|ΔU| ≤ 1e-9 et sortie identique à 1 et 8 fils ; non requis par §1.3, fourni pour WP12b/WP14.
- **HESS-FILS** : `cmp` des octets de sorties (NPY, JSON) à 1, 4 et 8 fils pour hv (ym4-gauche, s2-gauche, s2-additif), jvp (+ Ū), lmin (libre/kerB/tcov avec CG, tcov avec SVD, kerdu à tol 1e-8), espace kerdu.
- **Positivité des références** (§1.3, dernière phrase ; avenant **A4**, révisé le 26/10 après l'abandon de la campagne 1 : voir journal) : `lmin` calcule λ_min(PᵀQP) par LOBPCG (B = identité, tol 1e-8 relatif à la norme estimée, bloc 3, convergence exigée) et borne λ_max(PᵀQP) par la borne RIGOUREUSE 6β
  (Q/β = ¼ Σ_p J_pᵀJ_p, J_p J_pᵀ = 4·1 car les adjointes sont orthogonales, donc zᵀ(Q/β)z ≤ Σ_p |z_p|² = 6|z|², chaque lien appartenant à 6 plaquettes) ; refus (rc 8) si λ_min < 1e-8 · 6β ; λ_min, la borne et le rapport sont consignés dans chaque JSON (`q_restreinte`).
  Déclaré : un majorant de λ_max rend le contrôle plus strict (sûr) ; en revanche λ_min est une valeur de Ritz convergée (résidu ≤ 1e-8) : elle majore le vrai minimum et un résidu petit ne certifie pas l'extrémalité globale (ESTIMATION convergée, bloc de 3 vecteurs aléatoires). Les rapports λ_min/(6β) observés valent ≥ 0,02 : très loin du seuil 1e-8.
  (Première version d'A4 : λ_max aussi par LOBPCG ; abandonnée parce que le haut du spectre de Q_cov, groupé, ne converge pas en temps raisonnable.)
- **Finitude et convergence** (avenant **A6**) : tout script échoue (assertion) si une sortie, une référence ou un dénominateur n'est pas fini avant l'agrégation (un NaN ne peut pas passer par `max`) ; `kvu hess lmin` rend le code 8 si LOBPCG n'a pas convergé (`iter_max` atteint) et les scripts exigent `solveur.converge is True` ;
  les vecteurs projetés de HESS-KERDU doivent être de norme > 1e-8 (ratio défini). Politique d'échec : tout rc ≠ 0, toute non-convergence, toute assertion ⇒ gate FAIL, sans nouvelle tentative. Branche du logarithme : principale partout (θ ∈ [0, π] ; A = 2 log_q ; `rg::bloc::log_q` pour Ū) ; une configuration à lien exactement −1 n'est pas rejetée (A définie par la branche de `log_q`, cas de mesure nulle).
  Les `INFO-*` (suppléments) ne sont pas requis : leur PASS n'est pas exigé, mais un FAIL d'un `INFO-*` rend la campagne ROUGE (veto), décidé ici.
